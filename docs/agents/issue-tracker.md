# Issue tracker: GitHub

Issues for this project live in GitHub Issues at `coletangsy/clipfetch`.

Use the `gh` CLI with `--repo coletangsy/clipfetch` for issue operations because this workspace is not a Git clone.

## Conventions

- Create: `gh issue create --repo coletangsy/clipfetch`
- Read: `gh issue view <number> --repo coletangsy/clipfetch --comments`
- List: `gh issue list --repo coletangsy/clipfetch`
- Label: `gh issue edit <number> --repo coletangsy/clipfetch --add-label <label>`

## Pull requests as a triage surface

**PRs as a request surface: no.**

## When a skill says "publish to the issue tracker"

Create a GitHub issue in `coletangsy/clipfetch`.

## Blocking dependencies

Use GitHub's native issue dependencies. When unavailable, state the blocking issue numbers in the ticket body.
